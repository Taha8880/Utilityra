## ما الذي تراقبه الأتمتة؟

بعد نجاح تشغيل مولّد الحالة، سيعرض هذا الملف أحدث commits، ونتائج workflows، وفحوصات HTTP للمسارات التالية:
- الصفحة الرئيسية /
- /robots.txt
- /sitemap.xml
- /tools/word-counter
- /tools/pdf-to-text

المراقب الدوري المنفصل يعمل كل 30 دقيقة ويُنشئ GitHub Issue عند فشل فحص HTTP. الفحص لا يثبت صحة كل وظيفة داخل الأداة ولا يثبت فهرسة Google.

## قاعدة إعلان الإصلاح

لا تُعتبر المشكلة محلولة لمجرد تعديل الكود أو نجاح النشر. يجب أن ينجح الاختبار المرتبط بالمشكلة، وأن يُفحص الموقع الحي عند الحاجة. نتائج الاختبارات الفاشلة تظل مفتوحة حتى إصلاحها وإعادة اختبارها.
